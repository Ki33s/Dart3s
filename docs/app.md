# Приложение Dart3s для Windows

Запуск: ярлык **Dart3s** на рабочем столе или `C:\AI\Dart3s\Dart3s.lnk`.
Также можно дважды щёлкнуть `Dart3s.vbs`. Приложение работает в отдельном
нативном окне, без браузера и терминала.

1. Нажмите **«Выбрать файл»** или вставьте скопированную картинку через
   **«Вставить»** / **Ctrl+V**. Поддерживаются и файлы изображений в буфере.
   Когда фокус находится в поле параметра, Ctrl+V вставляет текст в это поле.
2. По умолчанию выбран **«Быстро · 512»**: Trellis2, 1000 полигонов,
   Remesh 128, текстуры 128×128, seed структуры 56, формы 42, текстуры 43.
   Режим пропускает детализацию 1024, использует 6 / 8 / 6 шагов структуры,
   формы и текстуры, один проход сглаживания Remesh, без отдельных карт AO
   и нормалей. Цвет, шероховатость и металличность сохраняются.
   **«Проверенный · 1024»** возвращает параметры топора: 10000 полигонов,
   Remesh 256, текстуры 256×256 и полный проход детализации.
3. Нажмите **«Создать 3D-модель»**. ComfyUI запустится автоматически;
   генерация выполняется установленным Comfy CLI в рабочем потоке.
   В правой панели **«Предпросмотр: короткая сторона, px»** выбирает
   128, 256 или 512 пикселей по короткой стороне; по умолчанию — 256.
   Длинная сторона сохраняет пропорции вида модели: например, 256×356
   либо 356×256. Это размер вида,
   параметры геометрии и текстур задаются отдельно.
4. После окончания прозвучит сигнал, модель сохранится в `outputs`,
   справа появится её предпросмотр. **«Сохранить GLB…»** копирует модель
   в выбранную папку. Кнопки поворота пересчитывают вид модели на CPU.

Кнопка **«Смотреть 3D-модель»** открывает готовый GLB в отдельном нативном
окне. Перетащите модель левой кнопкой и отпустите мышь, чтобы повернуть
ракурс по горизонтали и вертикали. Колесо приближает и отдаляет; кнопка
**«Сбросить ракурс»** или двойной щелчок возвращают исходный вид.
Просмотр использует настоящую геометрию и базовую текстуру GLB, работает
на CPU и не запускает генерацию. Углы и масштаб не меняют файл модели.
Вид обновляется после жеста; ожидающее обновление заменяется более новым.
Окно просмотра также доступно для моделей из истории. При следующем запуске
приложение восстанавливает последнюю готовую модель без звукового сигнала.

Процент относится к **текущему этапу**, например 7 из 12 итераций — 58%.
При следующем этапе счёт начинается заново. Для операций, которые не сообщают
числовой прогресс, отображается движущийся индикатор и название этапа.
Время внизу показывает длительность текущего запуска. Включённый по умолчанию
флажок **«Звук по окончании»** даёт три коротких тона после получения GLB.
Открытие старой модели через историю не сопровождается сигналом.

## Промежуточные виды

Картинка справа обновляется после готовых этапов: структура в виде облака
точек, геометрия без текстур, сетка после Remesh и уменьшения числа полигонов,
модель с базовой текстурой и окончательный результат. У сетки показывается
фактическое количество треугольников. В быстром режиме геометрия появляется
после формы 512 и штатного VAE Decode; в проверенном — после детализации
1024. Дополнительного декодирования нет.

Виды статичные, с общим ракурсом. Кадр имеет пропорции модели в выбранном
ракурсе; оба направления используют общий масштаб, без растяжения или
обрезки в квадрат. CPU-поток рисует только новые результаты; очередь хранит
один ожидающий вид и заменяет его более свежим. Быстрые этапы
могут объединяться: устаревшая картинка не публикуется поверх новой. Большие
сетки получают ограниченный прокси для отображения; исходная модель остаётся
полной. Предпросмотр не добавляет sampler- или VAE-проходов выбранного режима.
Четыре узла наблюдения передают полученные объекты без изменений.

Размеры быстрого режима подбираются автоматически:

| Полигонов | Remesh | Текстуры |
| --- | --- | --- |
| До 1000 | 128 | 128×128 |
| 1001–10000 | 256 | 256×256 |
| Больше 10000 | 256 | 512×512 |

Уменьшение полигонов задаёт предел итоговой сетки. Основное ускорение даёт
режим 512 и сокращение числа шагов. Настоящий запуск лодки на RX 6600 занял
120,975 с расчёта без кеша: 962 треугольника, текстуры 128×128. В окне
приложения проверены четыре промежуточных вида, GLB, финальный предпросмотр
589×256 и один сигнал завершения.

Результат топора, его точный workflow и код до оптимизации сохранены в
`backups/axe-working-20261014T164655Z.zip`; 688 файлов проверены по SHA-256.
В архиве есть `CHECKPOINT.json`. Веса и Python runtime остаются установленными
и не дублируются. GUI в архиве включает улучшения прогресса, сделанные после
запуска топора; точный исторический код GUI тогда не сохранялся отдельно.

Внизу показаны время текущего этапа и время последнего настоящего события
прогресса, включая число секунд без обновления. Пока GLB не сохранён,
промежуточные виды не включают сохранение модели и не подают сигнал.
Размер вида выбирается перед запуском; у готовой модели изменение размера
пересчитывает только CPU-предпросмотр. При увеличении окна изображение
подстраивается под доступную область.

PNG этапов и атомарный `latest.json` находятся в `outputs/<запуск>/previews`.
После закрытия и повторного подключения приложение читает исходный каталог
предпросмотров сохранённого задания.

**«Остановить»** отменяет только задание этого окна. После закрытия окна уже
отправленное задание продолжает работу в ComfyUI. При следующем запуске
**«Продолжить задание»** подключается к нему без повторной генерации.
При обрыве связи ID сохраняется в `.state/gui/pending.json`.
Настройки и снимки входных изображений находятся в `.state/gui`;
журнал каждого запуска — `outputs/<запуск>/generation.json`.

Статичные промежуточные виды строятся на CPU из готовых данных.
Кнопка **«Смотреть 3D-модель»** открывает итоговый GLB в отдельном
нативном Art3dViewer с вращением в реальном времени, без ограничения
размером промежуточных картинок. ЛКМ — вращение, колесо — масштаб,
ПКМ — перемещение, двойной щелчок — сброс камеры.
«Цвет / форма» переключает текстуру и нейтральную геометрию.
Повторное нажатие кнопки поднимает уже открытое окно этой модели.

Просмотрщик расположен в `D:\UnityProjects\Civilization\Builds\Art3dViewer`;
другой EXE можно указать переменной `DART3S_VIEWER_EXE`.
Для первого открытия GLB он использует установленный Blender 5.2
и сохраняет кэш рядом с EXE; исходный файл не изменяет.
Показывает базовую текстуру, остальные PBR-карты сохранены внутри GLB.

## Проверка

`scripts/test_gui_integration.py` проверяет настоящий Comfy CLI, поток
WebSocket-событий, процент 7/12, скачивание и сохранение GLB, нативный
предпросмотр, доставку четырёх этапов и однократный вызов звукового уведомления.
Локальный тестовый
сервер передаёт ранее полученную реальную модель; GPU-генерация в этом тесте
не выполняется. Отчёт: `logs/gui-integration-verification.json`.
Полная реальная генерация Trellis2 проверена отдельно, см. README.

`scripts/test_model_viewer.py` проверяет запуск Art3dViewer кнопкой приложения,
повторное использование окна, четыре разных ракурса реального GLB и
сохранность исходника. Отчёт: `logs/art3d-viewer-button-test/integration.json`.

`scripts/test_progress_nodes.py` проверяет V3 узлы, сохранность исходных
данных, UV/текстуры, ограничения больших сеток и замену устаревших кадров
на CPU. `scripts/test_progress_live.py` проверяет зарегистрированный узел
в настоящем ComfyUI на ранее полученном GLB, без новой генерации модели.
Отчёт — `logs/live-progress-verification.json`.

Восстановление ярлыков:

```powershell
.\scripts\Install-AppShortcut.ps1 -Desktop
```
