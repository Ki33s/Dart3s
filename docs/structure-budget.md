# Ограничение структуры и повтор seed

Основное окно использует лимит 4096 и один адаптивный повтор:
см. [Ранний отсев](adaptive-generation.md). Ниже описан самостоятельный
узел проверки структуры, который также можно применять без адаптивного клиента.
Значение 0 в лимите структуры отключает только этот узел проверки.

После обычного Structure sampler и VAE считаются активные ячейки исходной
структуры 32×32×32. Для батча используется максимум по одному объекту.
Допустимая структура передаётся дальше целиком, без удаления ячеек,
сжатия, изменения пропорций или дополнительного декодирования геометрии.

Если ячеек слишком много либо структура пустая, повторяются только исходный
Structure sampler и Structure VAE с seed+1, затем seed+2 (с переполнением uint64).
Используются те же conditioning, latent, CFG, sampler, scheduler, denoise и шаги.
Seed формы и текстур, Remesh и итоговое число полигонов не меняются.
Первый подходящий вариант принимается. После исчерпания попыток задание
останавливается до Shape sampler и текстур; очередь требует действий пользователя.

В папке каждого запуска сохраняется `structure-selection.json`: число элементов,
seed, статус каждой попытки и принятый seed. Время первой попытки в этом файле
относится только к проверке; время её генерации находится в обычном журнале.
Время повторов включает sampler и VAE.

4096 — начальная экспериментальная граница, а не доказанная граница качества.
Это бюджет исходной структуры: он не ограничивает все последующие промежуточные
тензоры, особенно при детализации 1024, и не гарантирует длительность или толщину
сетки. Изменение seed может не уменьшить сложность данного изображения.
Промежуточный предпросмотр с этим режимом пока несовместим; в основном окне он
уже отключён. Финальный просмотр модели сохраняется.

При закрытии окна Dart3s прекращается очередь, текущий элемент возвращается
в ожидание, отменяется его CLI и завершается только сервер ComfyUI этого проекта.
Небольшой поток очистки остаётся до завершения сервера и записывает результат
в `logs/gui-shutdown.json`. Готовые модели и входные изображения сохраняются.
Следующий запуск поднимает сервер заново. Принудительное завершение самого
GUI через диспетчер задач обходит обработчик закрытия Windows.
