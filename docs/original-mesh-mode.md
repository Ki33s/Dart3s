# Исходная геометрия как основной результат

В основном окне Dart3s генерация теперь использует `mesh_mode=original`:

1. Нейросеть рассчитывает структуру, форму и цвет с выбранными seed.
2. PaintMesh переносит рассчитанный базовый цвет в вершины исходной сетки.
3. MeshToFile3D сохраняет GLB. Вершины и треугольники не упрощаются.

Remesh, Decimate, UV-развёртка и UV/PBR-запекание не выполняются. Цвет хранится
стандартным атрибутом glTF COLOR_0, без отдельных карт текстур, normal/AO и
metallic/roughness. Поэтому в основном окне убраны неиспользуемые настройки
Remesh и размера UV-текстур. Выбор 512/1024 по-прежнему определяет нейрогенерацию
формы; seed цвета определяет цветовой результат.

Поле «Полигонов для low poly копии» не сокращает основную модель.
После генерации доступна отдельная кнопка «Создать low poly копию…».
CPU-обработка объединяет только вершины одной пространственной ячейки,
усредняет цвет и сохраняет отдельный GLB с уникальным именем. Нейросеть и
ComfyUI для этой операции не запускаются. Основной результат, сохранение и
история продолжают ссылаться на оригинал; копия открывается отдельно.

Перед публикацией копии проверяются смещение вершин (не более 5% диагонали),
изменение размеров по значимым осям (в пределах 10%) и площади поверхности
(65–135% исходной). При превышении копия не сохраняется. Эти проверки отсеивают
крупные изменения формы, но не гарантируют сохранение всех мелких деталей:
low poly остаётся отдельным результатом для визуальной проверки. Отмена копии
и её ошибка также сохраняют основной результат.

Предпросмотр готового GLB использует исходные треугольники, включая цвет вершин,
без кластеризованной proxy-сетки. Размер картинки меняет только отрисовку;
пропорции остаются неизменными. Отрисовка идёт на CPU в отдельном процессе.

## Реальная проверка 16 октября 2026

Проверена та же картинка камней, которая повреждалась после Decimate:
fast 512, seed структуры 56, формы 42, цвета 42. Запуск завершился за 393,609 с
с учётом старта сервера, сборки workflow и скачивания; серверный граф — 370,203 с.
Это один замер; колебания скорости sampler на данной системе остаются.

Готовый оригинал:
`outputs/original-mesh-verification/20261016T185709Z_af98a279/c78c4a37_000.glb`.

- 963585 вершин, 1920236 треугольников.
- Положения вершин и массив треугольников побитно совпали с исходным серым GLB
  из предыдущего теста. Цвета конечны и присутствуют в COLOR_0.
- API-граф и реальная история не содержат Remesh/Decimate/Unwrap/UV bake.
- Отдельная CPU-копия: 9824 треугольника, примерно 3 секунды с запуском Python.
  Максимальное смещение 0,02743 при диагонали 1,496; размеры 97,2–98,3%
  оригинала, площадь 104,2%. SHA256 оригинала после обработки не изменился.

Отчёты: `logs/original-mesh-verification.json`, `logs/original-mesh-integrity.json`,
`logs/original-mesh-gui-verification.json`; изображение — `logs/original-mesh-final.png`.
Проверено 77 unit-тестов в CLI Python и 2 CPU mesh-теста в portable Python,
а также отдельные проверки настоящего Tk-интерфейса с имитацией генерации:
очередь, отсев риска, low poly/ошибка/отмена, принудительная остановка и закрытие.

Это предотвращает повреждение уже рассчитанной формы этапами обработки.
Неудачная исходная форма нейросети всё ещё возможна на другой картинке.
Полная сетка может содержать миллионы треугольников; low poly не подменяет её.

Резервная копия до изменения: `backups/before-original-mesh-20261016T184117Z.zip`.
Старый `processed`-путь библиотеки и builder оставлен для существующих клиентов;
основное окно явно выбирает `original`. Приложение Details3D не изменялось.
Текущий `workflows/image-to-3d.json` также пересобран в режиме `original`.
