# Ранний отсев и один повтор

В основном окне Dart3s по умолчанию включена ранняя проверка:

- Лимит исходной структуры: 4096 активных элементов.
- Максимум один повтор с seed структуры + 1; значение 0 в поле повторов запрещает повтор.
- Бюджет ранней проверки обеих попыток: 180 секунд. Отсчёт начинается при
  расчёте структуры или формы, если структура уже находилась в кеше.
- В режиме «Быстро · 512» структура с декодированием должна уступить место
  форме за 75 секунд. Для стандартного режима с 12 шагами порог равен 150 секундам.
- Первые два шага базовой формы должны завершиться за 45 секунд.

После двух нормальных шагов формы контроль времени отключается: оставшаяся
генерация, декодирование, текстуры и экспорт выполняются с прежними настройками.
Сами samplers не сокращаются; seed формы и текстур, разрешения, пропорции и
число полигонов не меняются. Замедление поздних этапов этот режим пока не отсекает.

Два лёгких узла записывают `early-stage-3.json` и `early-stage-18.json`, когда
все входы соответствующего sampler готовы. Они передают исходный latent без
изменений, не выполняют GPU-вычислений и не создают предпросмотр. Клиент читает
точное время старта и следит за временем каждые 0.1 секунды даже без новых
сообщений прогресса. Проверка новых файлов ограничена четырьмя разами в секунду;
уже прочитанные файлы повторно не открываются. Это покрывает пропущенные события
Comfy CLI и подключение наблюдателя к уже начавшейся итерации.
При превышении лимита структуры или раннего времени клиент завершает свой CLI
наблюдения и останавливает сервер этого проекта. Перед остановкой проверяется,
что сервер не исполняет другую задачу и не содержит чужих ожидающих заданий.
В противном случае очередь приостанавливается с объяснением.
Новая попытка запускает свежий процесс ComfyUI: кеш и GPU-данные прежнего
процесса не переиспользуются. Время перезапуска входит в оставшийся бюджет.
Порог не является жёсткой гарантией общего времени: завершение драйвера,
проверка очереди и очистка процессов могут занять дополнительное время.

Если повтор тоже не проходит либо бюджет исчерпан, строка получает статус
«Пропущено · риск» и риск «Высокий». Очередь автоматически переходит к следующему
изображению. Окна технической ошибки нет. Один звуковой сигнал подаётся после
обработки очереди. Другие ошибки (например, сбой узла или сервера) не скрываются
и не запускают автоматические повторы.

В папке запуска `early-risk-attempts.json` хранит причины отказов, seed каждой
попытки, пути её `generation.json`, результаты очистки и принятый вариант.
`structure-selection.json` описывает отдельную попытку: внутренние повторы
узла при адаптивном режиме отключены. Приложение управляет повтором целиком.

Поле «Бюджет, с · 0 = выкл.» позволяет выбрать 120/180/240/300 секунд.
Значение 0 отключает адаптивный режим; самостоятельный лимит структуры остаётся.
Пороги этапов можно изменить в `.state/gui/early-risk-policy.json`:
`structure_seconds` (для быстрого режима), `shape_two_steps_seconds`.
Проверка не предсказывает качество: отказ означает высокий риск затрат времени.
Пороги пока экспериментальные, возможны ложные отказы.

API: `generate_3d(..., early_risk_seconds=180, structure_retries=1)`.
Без аргумента `early_risk_seconds` прежнее поведение API сохраняется.
Экспортированный ComfyUI JSON сам по себе не содержит клиентского контроля
времени и перезапуска сервера; для этого его должно запускать приложение Dart3s.
