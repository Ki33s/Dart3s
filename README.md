# Dart3s: ComfyUI → 3D

Локальная генерация GLB через Comfy CLI. ComfyUI portable v0.39.0 расположен в `ComfyUI_windows_portable`, CLI — в `.venv-cli`. Модели находятся в `models` и подключены через `extra_model_paths.yaml`.

## Запуск

Дважды щёлкните **Dart3s** на рабочем столе или `Dart3s.lnk` / `Dart3s.vbs`
в этой папке. Откроется отдельное приложение Windows. Выберите картинку или
вставьте её кнопкой **«Вставить»** / **Ctrl+V**, задайте параметры и нажмите
**«Создать 3D-модель»**. ComfyUI запускается автоматически.

Можно добавить несколько картинок и запустить последовательную очередь.
Приложение показывает текущий этап, реальные итерации и процент этого этапа,
время работы, время этапа и последнее обновление прогресса. Промежуточный
предпросмотр отключён; справа показывается готовый результат.
Размер статичного вида выбирается отдельно:
**128, 256 или 512 пикселей по короткой стороне**. Длинная сторона
увеличивается пропорционально модели, например 367×256. По умолчанию — 256.
После завершения всей очереди звучит сигнал; его можно отключить.
Кнопка **«Смотреть 3D-модель»** открывает готовый GLB в установленном
Art3dViewer: вращение ЛКМ, приближение колесом, перемещение ПКМ.
Модель можно сохранить как GLB или открыть её папку.
Кнопка **«История»** возвращает ранее полученные модели.
Подробности: [Интерфейс Windows](docs/app.md).

Основное окно сохраняет **исходную геометрию с цветом по вершинам**:
без Remesh, Decimate и UV-запекания, которые повреждали некоторые модели.
По умолчанию выбран **«Быстро · 512»**, шаги 6 / 8 / 6.
**«Проверенный · 1024»** добавляет детализацию формы.
Число полигонов относится только к отдельной кнопке **«Создать low poly копию…»**.
Копия создаётся на CPU без повторной нейрогенерации и не заменяет оригинал.
Подробности и реальные проверки: [режим исходной сетки](docs/original-mesh-mode.md).

Ограничение структуры и ранний отсев медленных вариантов работают для
каждой картинки очереди. Это контроль затрат, а не гарантия качества.
При закрытии основного окна завершаются принадлежащие программе фоновые процессы.
Текущий workflow для ComfyUI: `workflows/image-to-3d.json`.

Для запуска через PowerShell:

```powershell
cd C:\AI\Dart3s
.\Generate-3D.ps1 -Image 'C:\path\source.png' -Model pixal3d
```

Программа запускает сервер, если он ещё не работает, отправляет изображение и workflow через CLI, ожидает завершения и скачивает GLB в `outputs`. Результат содержит абсолютный путь файла, ID задания и путь к журналу. Продолжение существующего задания: `-Resume <prompt_id>`. CLI и существующие API-клиенты сохраняют прежний путь `processed`; для сохранения исходной сетки в Python API передайте `mesh_mode="original"`.

После скачивания и проверки GLB программа освобождает GPU-веса нейросетей,
если очередь сервера пуста. Сам ComfyUI продолжает работать; история и кеш
результатов сохраняются. Это предотвращает удержание весов предыдущего запуска
между генерациями. Результат обслуживания записывается в `generation.json`,
поле `memory_cleanup`; ошибка обслуживания не отменяет готовый GLB.

Для прямых команд CLI используйте `./Comfy.ps1 --json which` или
`./Comfy.ps1 --json jobs status <prompt_id>`. Обёртка выбирает локальный сервер и
конфигурацию этого проекта. Portable-сервер запускается через
`./scripts/Start-ComfyUI.ps1` своим embedded Python; `Generate-3D.ps1` делает это автоматически.

Параметры CLI по умолчанию (`standard`): Upsample **1024**, Remesh **256**, **10000** полигонов, все PBR-текстуры **256×256**. `-Model trellis2` переключает модель. Seed структуры — 56, общий seed двух шагов формы — 42, seed текстуры — 43. Все изменяемые параметры доступны в favorited inputs workflow `Dart3s Image to 3D`.

## Windows / RX 6600

[Официальная таблица AMD](https://github.com/ROCm/TheRock/blob/main/RELEASES.md) сопоставляет RX 6600 с `gfx1032`. Устанавливаются согласованные nightly-пакеты из [AMD](https://nightly.repo.amd.com/rocm/whl-next/): PyTorch 2.13.0 и ROCm 10.2.0a20261013, с extras `device-gfx1032`.

```powershell
.\scripts\Install-ROCm.ps1
```

Скрипт проверяет доступность GPU, FP32/FP16/BF16 matmul и Conv3d; отчёт — `logs/gpu-probe.json`. Скачать пакеты заранее можно через `scripts/download_amd_wheels.py`; модели — через `scripts/download_models_segmented.py`. Части загрузок сохраняются для продолжения, модели сверяются с SHA256 Hugging Face.

Исходная portable-сборка содержит PyTorch 2.9.1 + ROCm 7.2.1 и на этом компьютере падает в `torch.cuda.is_available()` с access violation. Установлено 32 ГБ RAM; при диагностике было свободно около 18,5 ГБ. Это сбой инициализации GPU, до загрузки 3D-моделей. После установки согласованных nightly-пакетов RX 6600 определилась как `gfx1032` с 8 ГБ VRAM; проверки FP32/FP16/BF16 matmul и Conv3d прошли. Отчёт — `logs/gpu-probe.json`. HIP в этом пакете сообщает версию 7.17.26405; версия дистрибутива ROCm — 10.2.0a20261013.

При полном тесте обнаружена отдельная несовместимость: `torch._int_mm` выдаёт `HIPBLAS_STATUS_INVALID_VALUE` на gfx1032. `scripts/configure_rocm_compat.py` включает существующий в ComfyUI путь с распаковкой весов слоя и обычным матричным умножением. Сжатые файлы моделей сохраняются; изменение ограничено gfx1032. Оригинал `comfy/model_management.py` сохранён с суффиксом `.py.pre-dart3s`. После обновления ComfyUI выполните этот скрипт повторно; `--check` проверяет наличие исправления. `Install-ROCm.ps1` применяет его автоматически. Изменение загружается после перезапуска сервера.

## Проверка программы

```powershell
.\.venv-cli\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты проверяют обработку CLI-ошибок, возобновление задания, автоматический запуск сервера, передачу GLB установленным Comfy CLI и headless-обёртку. Часть тестов требует локальных схем узлов и GLB из предыдущих запусков; эти данные в Git не входят. Полная генерация на GPU проверяется отдельным реальным заданием.

## Состав репозитория

В Git сохраняются исходники приложения, скрипты, тесты, документация,
рецепты/workflow и собственные узлы из `comfy_extensions/dart3s_progress`.
Веса моделей, ComfyUI portable, Python-окружения, исходные картинки,
сгенерированные GLB, кеши, журналы, резервные копии и личные настройки
остаются только на компьютере.

После клонирования установите portable ComfyUI и CLI по
[инструкции Windows](docs/windows-rocm.md), установите проектные CLI-исправления
через `scripts/configure_cli.py` и скопируйте собственные узлы:

```powershell
Copy-Item -LiteralPath .\comfy_extensions\dart3s_progress -Destination .\ComfyUI_windows_portable\ComfyUI\custom_nodes -Recurse -Force
```

Модели загружаются отдельно по `downloads/models.manifest.json`.
Внешний Art3dViewer также устанавливается отдельно; путь можно задать
переменной `DART3S_VIEWER_EXE`.
