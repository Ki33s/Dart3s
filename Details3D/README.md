# Детали — изображение в небольшой GLB

Отдельное приложение для досок, камней, кустов и других одиночных объектов
по картинке. Исходники и настройки основного Dart3s сохранены.

Запуск: ярлык «Детали 3D» либо `Details3D.vbs` в корне проекта.
Выберите файл или вставьте изображение из буфера Ctrl+V.
На картинке желательно показать один объект целиком, без окружающей сцены.
Изображение и промежуточные виды сохраняют пропорции.

По умолчанию: Trellis2, форма 512, шаги структуры/формы/текстуры 6/8/6,
500 треугольников, Remesh 128, текстуры 128×128.
Доступны 200, 500, 1000 и 2000 треугольников. Вариант 2000 использует
Remesh 256 и текстуры 256×256.
Флажок «Авто Remesh и текстуры» включает этот подбор по числу треугольников.
Ручной выбор одного из размеров отключает автоподбор и сохраняется
при запуске генерации и после переоткрытия программы.
Число треугольников ограничивает готовую сетку; сложность нейрогенерации
зависит от изображения. Отдельное окно само по себе не ускоряет нейросеть.

Прогресс, промежуточные виды, звук, история, сохранение GLB и запуск
настоящего Art3dViewer включены. Размер вида 128/256/512 — по короткой
стороне. Поворачивать, приближать и перемещать готовую модель можно
в Art3dViewer. Зависимости просмотрщика остаются установленными на компьютере.

Установленные ComfyUI, CLI, модели и проверенный генератор общие с Dart3s.
Оба приложения используют очередь одного сервера. Остановка относится
только к заданию данного окна. Закрытие окна не убивает ComfyUI.

Собственные данные:

- `Details3D/state/settings.json`, `pending.json`, `inputs/`;
- `outputs/details/<запуск>/`: GLB, workflow, журнал и промежуточные виды.

Код интерфейса и управления заданиями отделён от основного приложения.
Новые варианты нейропайплайна потребуют отдельной проверки качества и времени.
